# طبقه‌بندی میوه با ویژگی‌های رنگ و بافت

**درس:** آزمایشگاه هوش مصنوعی — گام اول  
**دانشجو:** حمیدرضا سجادیان  
**شماره دانشجویی:** 04120085705014  
**عنوان پروژه:** شناسایی نوع میوه با ویژگی‌های دستی و ماشین بردار پشتیبان (SVM)

## ۱. تعریف مسئله
عامل، یک تصویر شامل یک میوهٔ غالب را دریافت می‌کند و برچسب نوع میوه را پیش‌بینی می‌کند. این نسخه به‌جای kNN و Hu Moments به‌عنوان ویژگی اصلی، از ترکیب هیستوگرام رنگ HSV، توصیفگر بافت LBP و یک توصیفگر سادهٔ شکل استفاده می‌کند و طبقه‌بند SVM دارد.

## ۲. PEAS
| جزء | شرح |
|---|---|
| معیار عملکرد | Macro-F1 معیار اصلی؛ Accuracy، Precision/Recall هر کلاس، ماتریس درهم‌ریختگی و زمان پیش‌بینی معیارهای مکمل‌اند. |
| محیط | تصاویر برچسب‌دار میوه با تفاوت در نور، پس‌زمینه، زاویه، اندازه و میزان رسیدگی. |
| عملگرها | تولید برچسب پیش‌بینی‌شده، ذخیرهٔ نتایج ارزیابی و نمایش ماتریس درهم‌ریختگی. |
| حسگرها | پیکسل‌های تصویر ورودی و برچسب‌های پوشه‌ای که در مرحلهٔ آموزش استفاده می‌شوند. |

## ۳. ویژگی‌های محیط
| ویژگی | دسته‌بندی | توجیه |
|---|---|---|
| مشاهده‌پذیری | جزئی‌مشاهده‌پذیر | تصویر فقط نمای دوبعدی را نشان می‌دهد و اطلاعاتی مثل بافت داخلی یا وزن در دسترس نیست. |
| تعداد عامل | تک‌عاملی | یک برنامه تصویر را طبقه‌بندی می‌کند. |
| قطعیت | تصادفی در داده‌های واقعی | تغییر نور، نویز و ظاهر نمونه‌ها باعث می‌شود نتیجه برای همهٔ تصاویر قابل تضمین نباشد. با ورودی و مدل ثابت، اجرای پیش‌بینی تکرارپذیر است. |
| اپیزودیک/ترتیبی | اپیزودیک | هر تصویر مستقل ارزیابی می‌شود. |
| ایستا/پویا | ایستا | تصویر در حین پردازش ثابت است؛ دوربین زنده مسئله را پویا می‌کند. |
| گسسته/پیوسته | ترکیبی | کلاس خروجی گسسته است، اما ویژگی‌های عددی تصویر پیوسته‌مانند هستند. |

## ۴. ساختار
- `fruit_lab.ipynb`: دفترچهٔ اصلی برای بررسی داده، آموزش، ارزیابی و تحلیل.
- `check_env.ipynb`: بررسی محیط پایتون و کتابخانه‌ها.
- `src/fruit_model.py`: استخراج ویژگی‌های رنگ، بافت و شکل و آموزش SVM.
- `notes/evaluation_and_risks.md`: معیارها، روش ارزیابی و ریسک‌ها.
- `REPORT_TEMPLATE.md`: قالب گزارش قابل تکمیل پس از اجرای واقعی.

## ۵. قالب دیتاست
تصاویر را در پوشه‌های کلاس قرار دهید:
```text
data/fruit/
  apple/
    image1.jpg
  banana/
    image2.jpg
```
نام پوشه، برچسب کلاس خواهد بود. دیتاست در این ZIP گنجانده نشده است؛ بنابراین هیچ نتیجه یا دقت ساختگی گزارش نمی‌شود.

## ۶. اجرا
در پوشهٔ پروژه:
```bash
python -m pip install -r requirements.txt
python -m notebook
```
ابتدا `check_env.ipynb` و سپس `fruit_lab.ipynb` را باز کنید و Run All را اجرا کنید. تصاویر واقعی را به مسیر `data/fruit` اضافه کنید.

## ۷. محدودیت
این نمونه برای طبقه‌بندی تصویر با یک میوهٔ غالب طراحی شده و کادر مکان‌یابی یا تشخیص هم‌زمان چند میوه تولید نمی‌کند. عملکرد ویژگی‌های دستی به پس‌زمینه و کیفیت تصاویر وابسته است.
